# Owned native read adapter contract

This public synthetic fixture teaches an observation-only Python adapter. Implement `OwnedNativeReader(client)` and `create_adapter(config_path)` in `source/native_read.py` using the trusted SDK's `InstrumentAdapter` and `interface_process.NativeReadProcessClient`. Reject `None` and construct the client with `NativeReadProcessClient.from_file(config_path)` unchanged, never the browser client. Do not create paths, selectors, runtime definitions, shell commands or subprocesses. The separately reviewed private native definition/runtime is NOT included here or read during offline testing.

## Fixed command and worker methods

- Support exactly `native.status.read` version `1.0.0`, with empty arguments and a canonical Job UUID. No launch, focus, click, fill, screenshot or permission changes.
- `client.call("probe", stop_event=event)` returns `data` containing `source_kind: "native_macos"`, `owned_simulator: true`, an integer (not boolean) `actions_executed: 0`, strict boolean `read_access`, and the actual `target` identity. Reject another target/type before any execute, even if called directly outside the Gateway. `identity()` returns the target unchanged. `preflight(job)` maps `read_access` to `native.read_access`, with `operator_present: false` and `emergency_stop_available: false`. False means unavailable, not permission to grant Accessibility or start the application. `confirm(job)` returns `None`.
- Before each read, probe again with the actual stop event and require read access. Then call `client.call("execute", job_id=job.job_id, timeout_seconds=min(20, job.timeout_seconds), stop_event=stop_event)` exactly once. No retries after failure.
- The response contains the exact `job_id`, a 64-character lowercase hex `definition_digest`, and `data` retaining the same native/owned/zero-action fields plus `values: {"reader.status": TEXT, "reader.result": TEXT}`. Require exactly those two string values, each at most 4,096 UTF-8 bytes. Reject extra fields, booleans, numeric values or mismatched Jobs. Preserve text exactly, including an empty result; “Complete” is not evidence of a valid scientific measurement.
- Return exactly `operation_id` (the Job UUID), `definition_digest` from the response, the observed `values`, `observation_only: true` and `simulation_only: true`.

Propagate cancellation and worker failures, including unknown completion, without another read. `safe_stop(job, reason)` raises `RuntimeError`: stopping the local helper never certifies a selected application's or instrument's physical state. The Gateway, not this source, owns durable receipt recovery and reconciliation.

The installed native client verifies the separately pinned macOS build, application identity/process lifetime, window and selected controls. A restarted application requires renewed selection/review, never silent reattachment. This fixture accepts only the owned build-sealed simulator, not a vendor application with a similar name. Offline fixed tests inject a fake client; they require neither macOS nor a graphical session and must not call the native helper. Real native acceptance is a separate, explicitly authorized step. No tested hardware or scientific validation is claimed.
