# Owned stateful controlled-reader contract

This is a pure in-memory simulation, not a vendor interface. No network, process, files, GUI or physical device may be opened. Implement `ControlledReader(controller)` and `create_adapter(config_path)` in `source/controlled_reader.py`; independent tests supply a fake controller and intentionally vary the result. The factory rejects any non-null configuration and creates an owned simulator only. Declare no tested hardware; retain `simulation_only: true` in every output.

The exact command is `reader.measure@1.0.0` with only integer `sample_count` 1–96, not boolean. `identity()` delegates to the selected controller. `confirm()` returns a reference only for strict `controller.operator_confirmed is True`. `preflight()` observes `reader.ready` from strict readiness, Gateway ownership and idle state; it reports actual simulated operator presence and no physical emergency-stop availability.

Controller interface: `identity()`, `configure(count)`, `parameters()` returning exactly `{sample_count}`, `start()`, `poll()` returning `running`/`complete`, `result()`, and `stop()`. Observed fields: `state`, `owner` (`gateway` or `human`), `ready` and `operator_confirmed` booleans. The owned simulator begins idle and transitions running → complete after two polls. Its value is `round(0.42 * sample_count, 2)`, but the adapter must return the supplied controller's value, never recompute or substitute it. Factory identity describes `owned-memory-controlled-reader`, firmware `simulation`, application `controlled_reader`, application/driver `1.0.0`, OS `in-memory-simulation`.

Before configuration and again before starting, reject cancellation, non-Gateway ownership, missing readiness/confirmation and non-idle state. Configure parameters, read back the exact count, then start once. Lost start responses are errors and must never trigger another start. Poll with a bounded five-second deadline and cancellation checks before/after observations; unknown state or takeover fails rather than reporting completion. On `complete`, require exact result fields `sample_count`, finite numeric `value` (not bool), `unit: synthetic_unit`, `simulation_only: true`; sample/count and fresh parameter readback must match the request. Return actual controller data.

Errors propagate to Gateway reconciliation. `safe_stop()` is idempotent for this simulation: if not already idle/stopped, request stop once, then independently observe idle/stopped; otherwise raise and retain uncertainty. A no-op, a sent stop request, or a closed interface is not stop confirmation. This simulation-specific stopping contract must never be copied as physical hardware qualification. A real vendor adapter needs separate documented completion/stopping semantics and independent equipment tests; absent information must become questions, not an invented working driver.
