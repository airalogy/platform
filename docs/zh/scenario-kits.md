# 场景套件

场景套件把 Platform 已有能力组织成面向具体工作的流程。一个实验室可启用多个套件，各项目分别应用；样品、Protocol、Record、权限和分析仍使用同一套 Platform 资产模型。

## 首个完整流程

内置的**样品与数值结果**套件提供以下流程：

1. 实验室 Owner 或 Manager 在**实验室设置 → 场景套件**选择版本，预览保存位置和影响后确认启用。
2. 项目管理员进入**场景工作台**，预览并应用套件。首次创建共享样品类型还需要实验室资源管理权限。
3. 登记样品名称、实验室内唯一编号、类别，以及可选的来源和保存条件。沿用资源权限。样品属于实验室资源库，可跨项目复用；工作台明确显示实验室范围内有权访问的样品。
4. 选择样品并下载结果 CSV。模板只填入样品引用，方法、指标、有限数值、单位和测量时间由用户按实际实验填写。1.1.0 另有可选备注，1.0.0 仍可选择。
5. 使用现有 Record 导入器上传，保留标准 `var.*` 表头，完成校验、预览和确认。校验失败不创建任何 Record；修改文件后重试，不新增导入草稿或暂存模块。
6. 也可通过普通的样品测量 Protocol 手工填写 Record。资源链接固定样品修订，Record 保存对应的 Protocol 版本。
7. 进入分析，默认按**方法、指标、单位**分别统计，并拒绝缺失数值。检查实际 Record 范围与可编辑的分析方法后确认执行。沿用分析历史、来源清单、报告导出和方法复用能力。

全流程可以关闭 AI，也不依赖外部模型服务。套件不预设实验判定规则，不自动换算单位、补值或生成科学结论。不同方法、指标和单位分别分组；如实验背景仍有差异，用户应进一步筛选或区分，不能仅凭同名指标认为可以合并。

**材料样品与数值结果**是使用同一组模块的第二个组合示例，与首个套件共享样品身份，并创建独立、可编辑的测量 Protocol。它不代表已经实现化学结构、化学计量或化学专业判定能力。

## 升级、停用与留痕

- 模板是普通资产副本，操作凭证记录来源套件版本、初始 ProtocolVersion 和内容摘要。用户编辑不会改变内置目录。
- 应用或升级时可选择**保留已有模板**或**创建新的模板副本**。两者都不会覆盖用户修改或已有 Records；工作台可选择以前创建且仍有权访问的副本。
- 预览绑定用户、目标范围、安装修订、套件摘要与当前 Protocol 内容，有效期 15 分钟。期间发生变化需重新预览；确认请求 ID 保证重试不重复创建资产。
- 同一实验室的套件变更串行处理。编译、存储或权限复核失败时回滚数据库资产，并尝试清理本次上传的临时包。
- 仍有活跃项目应用时，不能停用实验室套件。存在未完成科研任务或分析时，项目套件停用会被阻止。停用关闭套件专用操作，普通 Protocol、资源、Record 和分析仍按原权限访问；它不代表禁止继续使用这些普通资产。
- 操作凭证不能修改或单独删除。经既有授权流程删除父级实验室或项目时，可连同删除该范围凭证，其他科研数据保留约束仍然有效。管理员可导出最近 200 条操作记录，导出不包含原始实验数据。
- 共享样品结构发生变更、被归档，或保留的样品类型编号已被占用时，明确报错，不静默替换已有类型。

## 实例配置与扩展边界

`SCENARIO_KIT_MODULES` 是实例模块白名单，默认值为 `airalogy.samples,airalogy.records,airalogy.analysis`；设为空可关闭套件启用和专用操作。它不会撤销普通资产访问权。成员、范围、模块可用性和操作权限均在 API 层校验，公共项目不会向非成员开放私有实验室样品或套件配置。

当前只接受随应用发布的内置版本清单和可信模板，不提供上传代码后直接执行的插件安装器，也不另建数据库、调度系统或自动授予权限。新增官方套件应经过目录配置、兼容测试和 Platform 正常发布。第三方扩展生态仍需独立的接口审查和验收，见 [RFC #12](https://github.com/airalogy/platform/issues/12)。

## 软件验收与试点边界

自动验收全部使用合成数据。参考计算在同一合成方法和指标下导入 `2 mg/L`、`4 mg/L`、`100 g/L`，两个分组的均值应分别为 `3 mg/L` 与 `100 g/L`。未填写的 CSV 必须报错且不产生 Record。

后端验收使用真实 Protocol 编译器、PostgreSQL、对象存储、Record 导入器、资源引用和分析工作进程；浏览器验收覆盖实验室启用、项目应用、登记、模板下载、导入校验、生成报告、中英文切换和关闭 AI 的窄屏操作。

尚未指定真实试点实验或仪器文件。真实实验室验收、专业计分规则、仪器专用导入适配、化学模块和第三方扩展安装应分别继续实施；合成软件验收不等于科学有效性验证。
