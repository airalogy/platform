# Airalogy Platform v0.4.0

在填写 Record 时，可以先问 Aira 某个 Protocol 字段的含义，再用“把刚才两项填为……”更新同一张表单。已有值被覆盖前可查看差异。模拟数据在独立预览中展示。实际提交仍使用 Record 表单的权限和校验流程。此版本使用 Masterbrain 0.14.0。

Lab 管理者可以开启外部 Agent 访问。用户为指定 Project 签发可撤销、有期限的令牌，使用 HTTP 或 MCP 读取授权数据、预览 CSV 导入或 Record 修订。每次写入都需要令牌所属用户在 Platform 网页确认。部署后默认关闭，见[外部 Agent 接入指南](../external-agent-access.md)。

本版还包含样品登记和数值结果场景套件、Record 资源引用修复，以及部署前的网段冲突检查。

## 从 v0.3.1 升级

数据库依次执行 0076（场景套件）、0077（Record 资源预留引用）、0078（外部访问策略、令牌、确认和审计）。在隔离副本上验证迁移与恢复，切换前核实恢复点，保留原有制品和配置，并按现网子网运行部署预检。回退时保留切换后的写入与审计记录，先验证旧版本与迁移后数据库的兼容性。详见[发布与部署规则](../release-and-deployment-identity.md)。

升级后可在专用测试 Project 中验证一次对话填表和模拟预览，再验证受限令牌读取、网页确认写入和撤销后的访问拒绝。
