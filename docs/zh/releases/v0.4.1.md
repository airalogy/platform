# Airalogy Platform v0.4.1

使用 Docker 执行 Protocol 时，可在 API 的 `AIRALOGY_PROTOCOL_EXECUTOR_NETWORK` 中填写现有专用网桥名称。创建网桥前和切换服务前均需运行部署网段预检。网桥应包含一个 IPv4 私有子网和可用网关。执行器每次运行时固定已检查的网络 ID，并通过该网关回连主机。指定网络失效时，执行器返回错误，用户可保留草稿。

配置留空时沿用原有 Docker 网络选择。本补丁没有新增数据库迁移。从 v0.3.1 直接升级还需完成 [v0.4.0 发布说明](./v0.4.0.md)中的数据库迁移和恢复验证。安装后通过 API 执行一次 Protocol，并从所选网桥验证主机端点可达。
