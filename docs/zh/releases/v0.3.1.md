# Airalogy Platform v0.3.1

本次兼容性补丁修复主站页脚显示。产品及所含组件版本统一为 0.3.1，不改变科研数据或权限行为。

## 修复内容

首页和普通页面恢复显示公司及已配置备案信息，即使浏览器曾保存 Record 页面的隐藏页脚状态，也无需用户清除本地数据。

Record 填写和报告页继续通过自身路由隐藏页脚，不再修改全局主题状态。回归覆盖旧缓存、手机和桌面布局、未登录访问，以及离开 Record 报告后的页面切换。

## 升级与恢复

相对 v0.3.0，本次没有新增数据库迁移、依赖升级或存储引擎变化。数据库版本仍为 `0075_legacy_file_metadata`；现有外部 PostgreSQL 和对象存储保持不变。

部署经过验证的发布集合，保留实例原有公司和备案配置以及上一版应用与 Web 资源。上线后验证刷新及页面切换后的页脚，不以清除浏览器数据作为修复手段。回退到 v0.3.0 无须数据库降级或恢复，应保留切换后的新增写入。更早部署仍须按[发布规范](../release-and-deployment-identity.md)完成实际源版本到目标版本的迁移与恢复验证。
