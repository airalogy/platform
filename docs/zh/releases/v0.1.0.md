# Airalogy Platform v0.1.0

Airalogy Platform Community Edition 首个正式版本，面向科研团队的协作、结构化实验记录、知识积累与受治理的科研自动化。

## 本版本包含

- **科研工作台**：按工作状态组织入口，继续最近工作，统一页面布局、字体、中英文术语与窄屏交互。
- **核心科研资产**：Lab、Project、成员权限、Protocol、Workflow 与 Record；支持协议创建/复用/导入、记录填写/校验/修订、检索和导出。Records 表格支持显示全部列、恢复默认列及保存列偏好，导出弹窗保留屏幕边距。
- **知识与日志**：个人、项目和实验室范围的 Knowledge、私有文献库与 Research Log，保留权限、来源、审核与资产关联。
- **科研任务与 Aira**：在明确范围、审批与资源约束下规划和执行任务，支持人工协作、计算执行、数据资产和结果留痕。AI 是可选辅助层；关闭 AI 不影响确定性核心操作。
- **仪器接入基础设施**：配对 Gateway、审核适配源码/包、独立安装、验收记录、启用授权、固定版本任务和原始文件回传。提供本地接入向导、限定软件观察、固定 HTTP/文件接口，以及浏览器和 macOS 原生界面参考实现。
- **私有部署**：单实验室初始化、独立账号权限、同源 `/docs/` 文档、版本与镜像摘要核验、备份恢复、升级回滚及脱敏支持包。
- **正式依赖**：直接使用已发布的 AIMD Core 2.16.0、Editor 1.12.0 和 Renderer 2.13.0，不再依赖临时 Renderer 补丁。

## 部署与验证

从本 Release 下载 `airalogy-platform-deploy-v0.1.0.tar.gz`，先核对同名 `.sha256` 文件。解压后按包内 `docs/zh/single-lab-deployment.md` 与 `docs/zh/release-and-deployment-identity.md` 配置，在 `deploy/single-lab` 目录运行 `./platformctl preflight`、`./platformctl install` 和 `./platformctl status`。

发布清单绑定 API、Web、Protocol Executor、PostgreSQL 的不可变镜像摘要及数据库迁移版本；镜像提供 `linux/amd64` 与 `linux/arm64`。Compute Runner 与 Instrument Gateway 的同版本 wheel/源码包单独随 Release 提供。设备主机安装 Gateway 前须核验来源证明，不能把安装成功视为设备验收通过。

正式发布流程检查组件版本、锁文件、测试、构建和来源证明；发布附件生成前对准确镜像集合执行新安装、账号权限、备份恢复及同版本升级回滚演练。完整浏览器、科研集成和仪器隔离测试由各自验证流程覆盖。

## 使用边界与升级提示

- **尚无真实仪器试点验收。** 接入能力的验证基于软件、模拟器和合成设备数据；不代表任意厂商设备可自动接入或安全远程控制。真实设备仍需现场人员核对身份、操作范围、联锁、停止行为和数据准确性，并独立授权。
- Gateway 本地工具以 POSIX 环境为基础；原生界面参考针对 macOS。浏览器模拟动作、原生只读观察与真实硬件控制的权限互不替代，不承诺 Windows 通用自动控制。
- AI 生成的源码、协议或建议必须经过相应预览、审核和执行门禁；本版本不承诺无人监督的端到端自主科研。
- 这是首个正式版本，没有更早正式版本可用于跨版本升级认证。同版本恢复演练不等于任意历史开发数据库均可直接升级。已有开发/试用实例应先备份，在隔离副本中验证迁移和恢复后再切换。
- 回滚可能恢复到备份时点，之后的数据会丢失；务必先备份并确认影响。备份包含敏感配置，应限制权限并加密保存在独立位置。
- 单实验室部署不是高可用或特定合规认证方案。不要将真实数据、密钥或客户运维资料提交到公开仓库。
