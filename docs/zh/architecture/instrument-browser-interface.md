# 浏览器界面后端

这是[仪器软件接入](./instrument-integration.md)的本地开发后端，不代表自主设备接入已全部完成。原先仅为模拟页面编写的浏览器操作，现已改用与本地命令行相同的、有界且需确认的执行会话。

## 当前边界

| 目标 | 当前能力 |
| --- | --- |
| 显式选择、按字节摘要固定的独立模拟 HTML | 观察、填写字面参数、点击、状态检查和结果回读 |
| 显式 HTTPS 应用地址（仅回环允许 HTTP） | 打开和观察；拒绝包含填写或点击的计划 |
| 已登录浏览器、工作站桌面、原生仪器软件 | 不接管、不控制 |
| 生产仪器指令与远程执行 | 必须走单独验收的 Gateway 适配器与 Instrument Job，本工具不提供该通道 |

打开页面或发送 GET 请求也可能初始化设备。“只读”名称或网络方法不构成物理安全证明。请先取得独立的本地授权，使用隔离训练/模拟环境。本轮软件验收未使用真实仪器。Windows 私有文件 ACL 尚未实现，执行时拒绝运行；Linux/macOS 合成 CI 不等于厂商软件或设备认证。

## 使用与确认

准备 Node 22+、仓库依赖和固定版本的 Playwright Chromium：

```bash
pnpm exec playwright install chromium
pnpm gateway:interface-example
```

示例命令仅创建所属用户可读写的临时定义和计划文件，输出绝对路径，不打开软件。将下列路径替换为实际值，证据目录须为所属用户独占：

```bash
pnpm gateway:interface preview --definition /absolute/definition.json --plan /absolute/plan.json
pnpm gateway:interface run --definition /absolute/definition.json --plan /absolute/plan.json --confirm <reviewed-sha256> --evidence /private/owner-only-directory --ack-new-run
```

预览属于**私有资料**。确认前检查软件/HTML 代码、版本标识、准确目标、控件、网络、遮挡规则、预算及每一步。摘要包含工具与浏览器库版本；打开前再次检查文件字节。不传计划时仅观察。目标、计划、文件或版本变化均需重新预览。本地确认只是操作者声明，不是 Platform 授权或源码审核。

`pnpm gateway:gui-demo` 仅通过同一后端运行内置模拟读数软件，保存本地证据并输出兼容演练包。独立 Python 契约检查固定预期结果 `0.84`，不根据实际返回值反推预期；其中 Gateway 控制权标签是模拟值，不证明真实设备归属。

## 契约与停止规则

`airalogy.browser-interface.v1` 包含：

- `target`：软件/版本/标题/语言、精确角色名称或测试标识限定的区域、明确来源及可见身份文字。
- `controls`：唯一 ID、语义定位、文字/值/勾选状态回读及明确允许的读取/填写/点击。
- `states`：字面控件值条件的组合，必须且只能匹配一个状态，未知或歧义状态拒绝执行。
- `network`：同源、准确的 GET/HEAD 地址及次数限制，初次 GET 也必须明确列出。受限本地请求层先检查响应，不跟随重定向；单响应流式读取最多 2 MiB、每会话最多 16 MiB，不传递浏览器 Cookie 或身份凭据。不支持通配符、初次加载后的导航或需要登录的应用。
- `blocked`、`privacy.redact`、`privacy.screenshot`：停止条件、遮挡规则及截图选择。
- `limits`：最多 900 秒、40 步、单次操作 10 秒、视口最大 1920 × 1080；最多保存 `2 × max_steps + 1` 次观察，控件值最多 4 KiB，可访问性树最多 32 KiB，单张截图最多 2 MiB。

`airalogy.interface-plan.v1` 是前后状态连续的字面步骤。填写必须回读一致且不声明状态转换。运行端只接受下一条已确认步骤，不接收 JS、任意选择器、Shell、坐标或模型指令。操作前重新检查身份、控件、启用状态和上次观察摘要，操作时固定选中的 DOM 元素，再检查结果。这不是原子性的物理互锁；快速变化的应用需要独立验收的适配器。操作返回时应已能观察到目标状态；不会隐式重试或无限轮询。

出现意外对话框、窗口、子框架、下载、WebSocket、被拒网络请求、过期观察、未知状态、超时或后置条件失败时停止。若已经尝试动作，则记录结果不确定；不自动重试、不重启重放。关闭浏览器**不等于确认仪器安全停止**，原有 Platform 停机确认和设备租约规则不变。

## 私有证据与模型使用

使用新的 `0700` 目录、独占创建的 `0600` 文件和带前序摘要的事件链。先持久化操作意图，再执行并记录回读结果或不确定状态。截图需显式开启，仅截选定区域，按页面级遮挡规则和密码框遮挡；与遮挡区域重叠的控件不得读取或填写。存在遮挡项或密码框时，整体省略可访问性树，避免使用不支持脱敏的序列化结果。不要把密码写入步骤。遮挡不是自动敏感信息识别，动态内容仍需人员核查；非密码也可能是敏感数据。

手工命令不会上传截图、证据或选定文件。经过本地审核后，可以将明确选定的文字观察作为 `materials` 交给独立授权的[源码开发流程](./instrument-source-authoring.md)。需要模型动态选择下一步时，使用独立授权的[有界界面探索](./instrument-interface-exploration.md)：仅选定的文字读回/动作进入 Aira，本地操作仍须精确策略确认。视觉理解、未知应用/原生软件发现与启动、受管理 GUI 执行与实机验证仍是 RFC 后续工作。

浏览器隔离和请求拦截是附加防护，不是操作系统安全沙箱，也不保证覆盖浏览器发起的所有传输。工具禁用 Service Worker、使用全新会话、不授予系统权限、不接管已有登录。只在更新且适当隔离的主机上运行经过审核的应用代码。版本文字和证据摘要属于观察/声明，不是固件身份或防篡改证明。

## 验证

`pnpm gateway:interface-test` 在真实 Chromium 中使用自有 HTML 和临时回环服务器，测试确认、状态漂移、重复控件、遮挡、弹窗、额外窗口、WebSocket、重定向、请求拒绝、预算、独立 CLI 进程和私有证据。修改后端、演示或相关依赖时，pre-push 会选择这些测试。独立 CI 覆盖 Linux/macOS 合成测试与工具打包，不上传界面证据。Gateway 演练契约及 Platform 仅处理数据的草稿 API 保持兼容。
