# 仪器软件接入

本次交付是 [RFC #5](https://github.com/airalogy/platform/issues/5) 的 **GUI 草稿与重放验证部分**，不是整个设备接入产品已经完成。

## 目标与权限边界

接入助手应能理解用户授权的仪器操作软件、观察人员示范、提出可复用适配方案并在部署前验证。优先使用支持的 API/SDK、可访问性控件或浏览器 DOM；视觉 Computer Use 需要独立后端及验收。启动软件可能初始化设备，不能默认视为只读。

观察、启动/导航、改变物理状态、安装和实机验收分别授权。窗口文字和说明书是不可信数据，不是授权指令。重放通过不授予实机控制权。Protocol 仍表达科研方法，接入草稿不是 Protocol 或 Instrument Command。

## 已可用流程

进入**实验室 → 资源库 → 仪器网关**，选择 Gateway，使用“仪器软件接入”。后端同时要求 Lab Owner/Manager 权限及对所选有效设备的 `equipment.service` 权限。草稿及历史不随公共 Project 公开。

1. 选择设备、填写接入目标；只有一个设备选项时自动继承。
2. 载入合成示例，或导入 JSON（最大 256 KiB）：准确的软件/版本/系统/语言、字面操作、来源声明、限制，以及独立提供的观察和预期结果。
3. 可选：让 Aira 根据这些观察和获授权说明编辑草稿。必须确认资料处理权限，部署模型可能为外部服务。单次调用限时 60 秒，不提供模型自行选工具、浏览、执行代码或循环重试。调用前后均检查权限。这不是自主桌面探索器；导入来源标签是用户声明，不是密码学证明。
4. 重放并预览。API 只解释数据，检查准确窗口/软件、交互会话、控制权、弹窗、控件唯一性、状态连续性、参数回读及预期结果。所有命令都需有通过场景才能整体通过；失败结果也可保存排查，不标为成功。
5. 确认预览。摘要绑定设备/网关修订、操作者、草稿版本和内容。过期或并发写入会拒绝，不覆盖别人修改。保存私有草稿、报告和审计快照，不创建指令或执行权限。
6. 重新打开、编辑、导出。导出旧版本不改变当前版或已安装软件；列表和历史目前各显示最近 100 条。

AI 关闭时，第 1–2、4–6 步仍可用。不自动采集真实资料或截图，不自动外发。导出文件默认属于实验室私有资料，分享前须单独审核。

## 本地工具

在源码仓库中使用 Python 3.11+：

```bash
pnpm gateway:rehearse --example
pnpm gateway:rehearse /absolute/path/to/rehearsal.json
```

离线工具不需要额外 Python 依赖或凭据。拒绝最终路径为符号链接或超大文件，不扫描相邻目录，不跟随包中路径，不执行内容。退出码：0 观察匹配，1 不匹配，2 输入无效。不自动上传结果。

安装仓库 Node 依赖及 Playwright Chromium 后：

```bash
pnpm gateway:gui-demo
```

演示只操作内置合成读数软件，通过真实浏览器控件填写样本数、点击模拟、读取结果，拒绝所有网络请求。预期结果独立固定，不从观察反推；输出可导入工作台。它不是通用浏览器控制器或原生 Windows 后端。

## 契约与剩余交付

`airalogy.gui-rehearsal.v1` 支持 `observe`、`read`、`invoke`、`set_value` 四种**与观察比对的步骤描述**，参数仅为字面标量，最多 10 条命令、每条 40 步、20 个场景。不包含 shell、代码、自动获取 URL、坐标、隐式重试或物理停止声明。在 Gateway 维护一份 Python 源码并生成 API 副本，CI 检查一致。

| 能力                                   | 状态                             |
| -------------------------------------- | -------------------------------- |
| 私有草稿/修订、导入导出、预览确认      | 已实现                           |
| 离线重放和合成软件浏览器演示           | 已实现，不代表实机证据           |
| 限于已有目标/控件/状态的可选 Aira 编辑 | 已实现，真实模型调用依赖部署配置 |
| 自主发现、启动和探索仪器软件           | 尚未实现                         |
| 原生可访问性及视觉控制后端             | 尚未实现，需明确目标软件/OS      |
| 沙箱驱动生成、可信包分发               | 尚未实现                         |
| 单次配对、安装回执、绑定资格           | 尚未实现                         |
| 仪器原始文件接收和草稿 DataAsset 映射  | 本部分尚未实现                   |
| 真实设备、OS 安装及安全验收            | 等待获授权试点和操作人员         |

已有 Gateway 签名、白名单、预约、审批、心跳和安全停止契约不变。目前没有试点型号、软件和 OS；不能关闭 RFC #5 或将本部分标为 P0-A/P0-B 整体验收完成。

迁移 `0048_instrument_integration_drafts` 新增草稿表；使用新界面前须按正常备份部署流程升级数据库。迁移测试用可销毁数据；降级删除草稿，不逆转物理操作或卸载适配器。
