# 仪器软件接入

本次交付涵盖 [RFC #5](https://github.com/airalogy/platform/issues/5) 的 **GUI 草稿/重放验证、有界浏览器开发后端、本地安装配对及沙箱适配包**，不是整个设备接入产品已经完成。

## 目标与权限边界

接入助手应能理解用户授权的仪器操作软件、观察人员示范、提出可复用适配方案并在部署前验证。优先使用支持的 API/SDK、可访问性控件或浏览器 DOM；视觉 Computer Use 需要独立后端及验收。启动软件可能初始化设备，不能默认视为只读。

观察、启动/导航、改变物理状态、安装和实机验收分别授权。窗口文字和说明书是不可信数据，不是授权指令。重放通过不授予实机控制权。Protocol 仍表达科研方法，接入草稿不是 Protocol 或 Instrument Command。

## 已可用流程

进入**实验室 → 资源库 → 仪器网关**，选择 Gateway 后打开共享设备工作台，设备只选一次。选择器按名称或编号检索有权管理、有效且支持预约的设备，支持显式分页；不再受资源库前一页的普通资源数量影响。仅真正唯一的选项自动继承。链接中的设备已失效或无权访问时清空并提示，不静默替换为其他设备。

| 阶段       | 用途                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| 连接配对   | 配对本地工作站并核对身份。                                                |
| 准备适配包 | 查找/导入已有包、理解软件、开发源码、有限界面探索或 GUI 草稿演练。        |
| 安装与验收 | 授权准确安装、查看回执，并在安装详情内分别验收及授权启用。                |
| 指令管理   | 查看和管理该设备的准确指令版本；科研执行仍走 Task、环境、预约和审批流程。 |

这些阶段是导航，**不是完成标记**。打开某一步不授予权限，也不表示硬件就绪。适配包复用仍在 Lab 范围，其他工具继承设备上下文；切换准备工具保留已打开工具的本地表单。切换设备或 Gateway 会提醒未保存表单将关闭，已有工作留在原范围。链接只记住网关、设备、阶段及工具，不含凭据、草稿或权限；刷新后由 API 重新鉴权。

安装和演练列表先按设备筛选，再分页。在**安装与验收**中清空设备选择，可查看整个 Gateway 的安装历史，包括已归档或停用的设备；重新选择有效设备前不能新增安装授权。导航不会触发 AI、启动驱动、安装或设备动作。该工作台不替代工作站本地安装或真实仪器验收。

GUI 草稿入口为**准备适配包 → 演练 GUI 草稿**。后端同时要求 Lab Owner/Manager 权限及对所选有效设备的 `equipment.service` 权限。草稿及历史不随公共 Project 公开。

1. 使用共享设备上下文填写接入目标。
2. 载入合成示例，或导入 JSON（最大 256 KiB）：准确的软件/版本/系统/语言、字面操作、来源声明、限制，以及独立提供的观察和预期结果。
3. 可选：让 Aira 根据这些观察和获授权说明编辑草稿。必须确认资料处理权限，部署模型可能为外部服务。单次调用限时 60 秒，不提供模型自行选工具、浏览、执行代码或循环重试。调用前后均检查权限。这不是自主桌面探索器；导入来源标签是用户声明，不是密码学证明。
4. 重放并预览。API 只解释数据，检查准确窗口/软件、交互会话、控制权、弹窗、控件唯一性、状态连续性、参数回读及预期结果。所有命令都需有通过场景才能整体通过；失败结果也可保存排查，不标为成功。
5. 确认预览。摘要绑定设备/网关修订、操作者、草稿版本和内容。过期或并发写入会拒绝，不覆盖别人修改。保存私有草稿、报告和审计快照，不创建指令或执行权限。
6. 重新打开、编辑、导出。导出旧版本不改变当前版或已安装软件；列表和历史目前各显示最近 100 条。

AI 关闭时，第 1–2、4–6 步仍可用。不自动采集真实资料或截图，不自动外发。导出文件默认属于实验室私有资料，分享前须单独审核。

## 停止不确定性与设备占用

执行报错不等于物理设备已停止。任务启动后，失败回调若未以严格布尔值 `safe_stop_confirmed: true` 明确确认停止，将保持 `stop_requested`、暂停科研运行并保留原租约身份以供恢复。网关仅在有时限的安全停止核对成功后发送确认；回执丢失只重传结果，不重新执行物理命令，平台未确认终态时本地状态不会清理。

设备按 Resource 跨所有网关互斥，而非仅按单一控制端或预约互斥。已有领用、运行或请求停止的任务时，即使原预约到期，另一网关也不能接管；原网关的凭据轮换和重新配对也保持阻塞。这是软件保护，不替代急停电路，也不独立证明厂商硬件安全。升级时应同时更新 API 和网关；旧客户端缺少明确确认时，启动后报错将保持阻塞，需通过更新后的网关恢复。升级前的历史终态失败不会被追认为安全：重新启用设备前应检查并核对任何曾经不确定的物理状态。

## 本地工具

在源码仓库中使用 Python 3.11+：

```bash
pnpm gateway:rehearse --example
pnpm gateway:rehearse /absolute/path/to/rehearsal.json
```

离线工具不需要额外 Python 依赖或凭据。拒绝最终路径为符号链接或超大文件，不扫描相邻目录，不跟随包中路径，不执行内容。退出码：0 观察匹配，1 不匹配，2 输入无效。不自动上传结果。

安装仓库 Node 依赖及 Playwright Chromium 后：

```bash
pnpm gateway:gui-demo
```

演示只通过共享的[浏览器界面后端](./instrument-browser-interface.md)操作内置合成读数软件：填写样本数、点击模拟、读取结果，拒绝所有网络请求。预期结果独立固定，不从观察反推；输出可导入工作台，并保存本地私有证据。独立的 `gateway:interface` 命令支持显式选择、按摘要确认的模拟 HTML，以及仅观察的 URL 目标；不是原生 Windows 后端或生产仪器控制器。

### 本地浏览器接入向导

首次安装可使用独立确认的 [SDK 来源核验与隔离安装引导](./instrument-sdk-installation.md)，或独立可信的手工 SDK 安装。接入向导本身不负责证明自身可信。

在已获授权、已安装审核过的 Gateway SDK 的 POSIX 工作站运行：

```bash
airalogy-instrument-setup --root /absolute/private/service-directory
```

源码仓库中使用 `pnpm gateway:setup --root /absolute/private/service-directory`。将示例替换成已存在、属于服务账户、权限为 `0700` 的真实目录。**必须与已有 Gateway 的任务日志共用服务目录**，不能另建目录绕过尚未核对的任务。此向导不是 SDK 引导安装器，也不是无人值守服务；要求 Python 3.11+，不支持 Windows ACL 存储或厂商原生软件安装。

手动在工作站浏览器打开命令显示的准确私有地址，不自动启动任何应用。双语向导提供：

1. **核对接入位置：**确认部署的 API 地址、准确 Lab/Gateway ID 和工作站名称。确认后独占创建 `0600` 的 `gateway.json`；已有身份只复用、不覆盖，此时不请求 Platform。
2. **配对：**填写 Platform 的短时配对码，比对完整指纹，再在 Platform 独立批准。配对码不保存；已保存回执可在刷新后查询状态，Gateway 仍停用。
3. **选择本地文件：**选择经过测试的 Adapter Package ZIP、可信 SDK wheel 和私有 JSON 配置。选择时仅复制到本机私有 `setup-inputs` 目录。SDK SHA-256 必须来自独立可信来源，界面不会把文件自身摘要当作信任依据。
4. **预览并确认：**核对固定的包、SDK、配置、环境及位置。确认五分钟有效且仅能使用一次，创建私有安装请求前再次核对输入摘要及身份。只下载**公开请求**交给 Platform 的**安装与验收**工作台，不包含运行/安装凭据、本地路径或配置正文。
5. **独立审批及安装：**在 Platform 审核适配包来源并批准准确设备的安装，再到本地向导查询授权。独立审核源码及依赖，明确确认非活动安装。复用的安装管理器重新检查当前授权和文件，锁定已有任务日志，在平台确认前保存持久回执；不会导入/启动驱动或启用网关。之后仍需独立验收、批准活动版本，再使用单独的本地启动器。

刷新只恢复普通私有文件中的元数据，不表示可以重复执行。配对响应丢失且尚未保存回执时，可在有效期内以原身份提交同一配对码，或使用下方 CLI 的状态/恢复流程，不另建凭据。安装结果不确定时选择原请求，先查询状态再确认核对；已有持久安装回执只重传，不重新安装、不启动驱动。到期/撤销授权、未核对任务及停止日志均拒绝继续。重启向导使未确认预览失效，但保留请求；会话到期后须使用**同一目录**重新启动。Ctrl-C 关闭向导，不停止独立运行的 Gateway。

安全边界：服务只监听 `127.0.0.1`，校验准确 Host/Origin；每次 API/文件复制请求都要求一小时有效的不可猜测会话凭据。凭据保留在私有 URL 的片段中以支持刷新，不进入 URL 请求、日志或 referrer。请勿分享、收藏同步此地址，避免使用共享浏览器配置。没有 CORS、远程资源、模型调用、shell 端点、任意文件下载路由或浏览器持久存储。这不隔离同一操作系统用户下的恶意程序，应使用专用服务账户。公开请求通过人工下载/上传交接，不由 Platform 跨域控制本地服务。

限制：JSON 配置 16 KiB，适配包/SDK 单文件 64 MiB，保留副本最多 64 个 / 256 MiB，服务目录元数据最多扫描 1,000 项。副本在私有目录中保留以供审计和恢复，不自动删除；人工清理前应核对请求引用和保留要求。高级检查仍可使用原有 CLI；不会静默丢弃数据，也不会在响应不确定时报告安装成功。

## 契约与剩余交付

### 本地安装配对

实验室管理员在网关面板先停用网关，完成或安全停止执行中的任务，再预览并创建配对码。配对码十分钟有效，仅显示一次；新建会取消之前未完成的配对，不立即更换现有凭据。

在获授权的本地工作站创建服务账户专用目录（权限 `0700`），运行：

```bash
pnpm gateway:pair --credential-file /private/service-directory/gateway.json --platform-url https://lab.example.edu/api --lab-id <Lab-UUID> --gateway-id <Gateway-UUID> --client-name "Local station"
```

请替换示例中的目录、平台地址和 UUID。已安装 Gateway 包时也可使用 `python -m airalogy_instrument_gateway.pairing_cli`。核对地址和范围后，在隐藏输入提示中输入配对码，不要将配对码写到命令参数、聊天或 Issue。

本地先独占创建 `0600` 凭据文件，然后向所选平台提交身份摘要。不启动适配器、不领取任务。管理员刷新页面，核对两端完整指纹，预览并确认；确认使旧凭据失效并记录审计，**网关仍保持停用**。客户端名称是声明，不是实机证明。已有指令白名单和审批不会因配对而新增或放宽。

网络响应丢失后可用 `--credential-file <原文件> --resume` 重试同一身份；确认结果可用 `--credential-file <原文件> --status <配对 UUID>` 查询。取消/过期需重新创建配对码，不覆盖旧凭据文件。运行服务时使用 `AIRALOGY_GATEWAY_CREDENTIAL_FILE` 代替 `AIRALOGY_GATEWAY_TOKEN`；平台地址继承自配对文件，冲突覆盖会拒绝。非回环地址仅支持 HTTPS，拒绝跳转。

私有目录、文件权限、符号链接、硬链接、覆盖和目标地址均有检查。这是 POSIX 软件验收范围；Windows ACL 及服务安装未实现，工具会明确拒绝不支持的凭据存储。旧的服务管理器密钥配置仍可使用。配对完成不代表已安装适配包或完成设备验收。

### 状态矩阵

现在可以构建实际 Python 驱动包、不执行代码地检查内容、在隔离容器中测试，并准备 POSIX 未启用安装快照。参见[仪器适配包](./instrument-adapter-packages.md)中的显式文件选择、不可变产物与安全边界。准备快照不代表启用仪器驱动。

`airalogy.gui-rehearsal.v1` 支持 `observe`、`read`、`invoke`、`set_value` 四种**与观察比对的步骤描述**，参数仅为字面标量，最多 10 条命令、每条 40 步、20 个场景。不包含 shell、代码、自动获取 URL、坐标、隐式重试或物理停止声明。在 Gateway 维护一份 Python 源码并生成 API 副本，CI 检查一致。
