# 开始使用 Airalogy Platform

Airalogy Platform 将研究流程、按照流程采集的数据以及参与人员持续关联起来。不同机构可采用开放注册、邀请加入或统一分配账号等不同方式；Community Edition 与私有化实例中的核心研究工作方式保持一致。

## 登录或加入实例

- 如果实例允许自助注册，请按注册页提示创建账号，然后登录。
- 如果实例采用邀请制，请使用实验室管理员提供的邀请链接。已有账号可在登录后接受邀请，新用户通过邀请流程创建账号。
- 如果注册已关闭，请向实例运维人员或实验室管理员确认账号开通方式。

不要复用其他服务的密码。密码重置链接通常是短期有效的敏感信息，不要转发给他人。

## 理解工作空间

Platform 使用四类相互关联的资源：

| 资源             | 用途                                               |
| ---------------- | -------------------------------------------------- |
| Lab（实验室）    | 承载顶层工作空间、成员关系和治理规则。             |
| Project（项目）  | 围绕研究任务、团队或目标组织工作。                 |
| Protocol（协议） | 定义要执行的流程以及需要记录的结构化字段。         |
| Record（记录）   | 保存一次执行中已经完成或正在填写的 Protocol 数据。 |

有的部署只显示一个固定 Lab，有的部署允许用户加入多个 Lab。Project 和 Protocol 还可有更细的访问规则，因此能看到 Lab 不代表能查看其中所有资源。

## 建议的首次使用流程

1. 进入实际承担研究工作的 Lab 和 Project。
2. 选择已有 Protocol；如果角色允许，也可以新建 Protocol。
3. 记录前检查 Protocol 的说明、字段、步骤、检查项和当前版本。
4. 新建 Record，填写要求的值，按需上传文件，然后保存或提交。
5. 重新打开 Record，确认值、文件和所属上下文正确。
6. 通过 Platform 的成员与访问控制将 Project 或 Protocol 分享给协作者。
