# Record

Record 保存一次 Protocol 执行的数据，包括填写的值、步骤与检查项状态、备注、文件、来源信息以及该 Protocol 支持的修订历史。

## 创建 Record

1. 打开目标 Protocol，选择记录操作。
2. 确认 Protocol 版本以及所属 Lab、Project。
3. 按表单要求的单位和格式填写必填字段。
4. 通过页面提供的上传控件添加文件，使 Platform 能保存稳定的文件标识。
5. 解决校验提示，然后按页面流程保存或提交。

不要在 Record 中填写密码、密钥或与研究无关的个人信息。文件命名、保留期限和敏感数据处理应遵循所在机构的规定。

## 校验与修订

表单由 Protocol 的结构化字段生成。校验可以发现缺失值和不兼容类型，但无法判断观察结果在科学上是否正确。提交前应复核异常数值。

在允许修改时，Platform 会按当前功能和策略保留修订信息。重要更正应通过备注或指定原因字段解释。不要为了让结果更“整齐”而直接覆盖观察值；应保留原始观察并记录更正过程。

## 文件

文件本体由实例配置的存储后端保存，Record 中保留稳定文件身份。Lab 可能使用 MinIO、对象存储或其他由运维方管理的后端。删除源文件前应确认上传已经完成；不可替代的数据还需遵循运维方的备份策略。

## 审阅与复用

比较 Record 时，应同时检查 Project、Protocol、记录人、时间和版本上下文。不同 Protocol 版本中同名字段不一定具有相同含义或单位。

将已有表格导入 Record 或生成授权归档，见[导入与导出](./import-export)。
