# 搜索

搜索用于查找当前账号有权访问的资源。根据 Platform 版本和部署配置，结果可以包含 Protocol、Record、讨论、Project 或其他已建立索引的对象。

## 提高搜索效率

- 从具有区分度的 Protocol、Project、样本或字段关键词开始。
- 界面提供筛选时，缩小到特定 Lab 或 Project。
- 名称容易重复时使用稳定 ID。
- 使用结果前检查其 Lab、Project、Protocol 版本、记录人和日期。

搜索结果反映当前账号的访问权限。其他成员能找到而你看不到的资源，可能属于私有范围、其他工作空间，或尚未完成索引。

## 找不到预期结果时

1. 直接进入预期的 Lab 或 Project，确认自己的成员关系。
2. 检查拼写、ID、筛选条件和时间范围。
3. 确认资源已保存，且没有被归档或删除。
4. 请资源所有者核对访问设置，不要优先要求制作重复副本。

搜索是发现工具，不替代受治理的资产清单或备份。需要满足保留要求时，应使用获准的导出和运维备份。
